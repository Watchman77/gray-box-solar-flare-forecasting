## Positioning consequence

The verified literature supports a conservative novelty claim: prior work already covers operational verification, temporal modelling, multimodality, ensemble forecasting, simulated real-time evaluation and uncertainty estimation. The manuscript should claim novelty for the **integrated frozen trust-routing experiment and its joint evidence**, not for any single ingredient.
